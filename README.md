# Thyroid Phantom Development for Ultrasound-Based Cancer Detection

## 📌 Overview
This project focuses on developing a realistic thyroid phantom that simulates both healthy and cancerous tissue for biomedical imaging and diagnostic applications.

The goal is to improve the accuracy of ultrasound-based thyroid cancer detection by integrating electrical stimulation and analyzing imaging responses.

---

## 🎯 Objectives
- Simulate real thyroid tissue properties
- Improve early cancer detection using ultrasound imaging
- Study the effect of electrical current and magnetic fields on imaging quality
- Develop a cost-effective and reproducible phantom model

---

## 🛠️ Methodology

### 1. 3D Modeling & Printing
- Designed a thyroid model using CAD software  
- Converted to STL format and printed using a 3D printer  

### 2. Material Development
- Used sodium alginate, agar, and graphite  
- Achieved tissue-like electrical and acoustic properties  

### 3. Electrical System
- Implemented a constant current source (Howland current pump)  
- Studied electrical conductivity and impedance  

### 4. Imaging & Testing
- Ultrasound imaging (B-mode)  
- Thermal imaging analysis  
- Magnetic field interaction experiments  

---

## 📊 Results
- Successfully simulated thyroid tissue behavior  
- Cancer-like regions were detectable using ultrasound  
- Electrical and magnetic stimulation enhanced imaging analysis  

---

## 🔬 Technologies Used
